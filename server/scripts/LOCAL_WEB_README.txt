本机 ETF 网页

双击桌面“打开ETF资金观察.cmd”，浏览器将打开 http://127.0.0.1:4173/。
入口只在当前电脑可用。关闭浏览器不会终止后台服务；重启电脑后再次双击即可。
服务绑定本机环回地址，只提供读取，不需要服务令牌或上传密钥。

数据来源仍为项目原来的已验证快照，不复制或改动数据库。
web-trial/.local/local-view.json 记录当前选中的个股和历史快照版本。
使用 set_local_view.py --stock 个股版本 --history 历史版本 校验并原子切换。
只有完成数据审查、文件校验的快照才可选择；不能把独立历史库的覆盖当作个股模型覆盖。
更新选择后在网页点“刷新数据”即可读取新版本，无需重启后台服务。

open_local_web.ps1 启动时检查端口和应用标识，不会停止占用端口的其他程序。
启动日志和运行检查保存在桌面 ETF更新日志 下的当天日期文件夹。
原托管网址与本机入口相互独立。远程访问仍须满足 Sites 的仅本人权限及平台安全规则。
