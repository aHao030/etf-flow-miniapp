# M4/M5 测试与提审预研（v0.1 草稿）

> 依据：计划书 §6（M4/M5 里程碑）、§7（合规与风险）、§8.1 已采纳方案（个人主体开发+体验版内测→公开上架走企业主体；免费源；盘后 T+1；行业主题+主流宽基；自用/小圈子）。本文为预研框架，M4 开工后按实际实现细化；测试用例与对账脚本届时落 `tests/`。

## 1. 合规要点梳理（§7 展开）

### 1.1 类目与资质
| 类目（金融业一级，公开资料口径） | 官方资质要求 | 对本项目的影响 |
|---|---|---|
| 证券/期货 | 《经营证券期货业务许可证》 | 不可行，规避 |
| 基金 | 《经营证券期货业务许可证》（含基金范围）等 | 不可行，规避 |
| 证券、期货投资咨询 | 《证券投资咨询业务资格证书》 | 红线规避：产品不含咨询/建议功能 |
| 股票信息服务平台 | 《增值电信业务经营许可证》（含财经投资类电子公告）+ 上交所/深交所证券信息经营许可合同 | 公开上架最贴近的正规路径，资质重、需企业主体 |
| 工具类（信息查询等） | 无特殊资质 | 风险：服务描述涉行情/个股会被判"类目不符" |

- 金融业类目仅企业主体可开通，个人主体无法认证开通 → 与 §8.1 一致：体验版内测不涉类目；公开上架前注册企业主体 + 微信认证；
- **小程序 ICP 备案**：2023-09 起新小程序发布前必须完成备案（自建服务器另需域名备案；云开发路线可省域名备案）；
- 最终类目与资质**以小程序后台现行要求为准**，M5 开工第一件事逐类目核对（上表为公开资料参考）。

### 1.2 不荐股红线
- 禁用词：买入/卖出/推荐/建议/加仓/抄底/上车/目标价/评级/收益预测等；榜单只陈述"估算净流入"事实，不加趋势解读与操作暗示；
- 不展示用户收益、不承诺收益、无付费荐股功能；全页面免责声明 + 数据口径说明页（文案见 §3）。

### 1.3 "估算值"口径披露（强制）
- 全数据页底部固定标注 + 数据说明页：
  > 本页面数据为估算值：基于 ETF 份额变化与持仓权重推算的潜在资金流，非真实买卖资金数据，可能存在较大误差，仅供研究参考，不构成任何投资建议。
- 数据说明页披露：计算公式、权重来源（PCF 优先/季报回退）、更新频率（每日盘后 T+1）、误差来源（季报滞后、权重近似、申赎≠当日买卖）。

### 1.4 数据来源授权
- V1 全公开免费源（交易所披露/天天基金/东财；AKShare 为接口聚合层），页面标注来源与更新时间；
- 商用前逐源确认服务条款（AKShare 聚合层与其底层网页源均须核查）；
- 产品只展示"估算资金流"、不展示行情快照，敏感度较低；文案避免"实时行情"字眼；公开运营若扩大范围，评估沪深交易所证券信息经营许可。

### 1.5 隐私
- 最小化收集：不采集手机号/昵称头像；自选优先本地缓存，云端持久化仅存 openid+代码列表；
- 后台配置《用户隐私保护指引》（声明 openid、自选记录、订阅消息），隐私弹窗（onNeedPrivacyAuthorization）真机验证；
- 订阅消息：用户主动订阅、提醒类模板、禁营销推送。

## 2. M4 测试计划框架

### 2.1 数据对账抽样方法（每日自动对账 + 周度深度复核）
| 层 | 对象 | 抽样 | 方法 | 通过标准 |
|---|---|---|---|---|
| L1 源对账 | ETF 份额/净值 | ≥10 只（宽基 5 + 行业主题 5）× 近 20 交易日 | 库内值 vs 交易所/天天基金披露逐日核对 | 一致率 100%（差异须可解释） |
| L2 复算对账 | 个股资金流 | ≥10 只成分股，覆盖榜单头部/中游/尾部 | 原始数据独立重算单日/5日/20日/流入强度，比对 API 输出 | 误差 ≤0.1% |
| L3 界面一致性 | 榜单/详情/拆解 | 三榜单 TOP20；每只股票 ETF 贡献拆解 | 榜单与模型输出一致；ΣETF 贡献 = 个股总流入 | 排序全对；合计误差 ≤1 元 |

- 异常用例：份额突变（分红/份额折算）、权重缺失回退、停牌个股、ETF 上市首日/清盘、流通市值缺失、节后首日；
- 对账口径与 quant-analyst 模型说明文档对齐，脚本落 `tests/`。

### 2.2 真机测试点（体验版内测）
- **设备矩阵**：iOS ≥1、Android 低端 + 主流各 ≥1、开发者工具回归；
- **功能**：4 页面全链路（榜单切换/筛选、详情图表、ETF 页、自选增删与杀进程重进持久化、订阅消息触发）、时间边界（18:00 更新前后缓存一致性）、停盘日兜底；
- **性能**：首屏 <2s（弱网 <3s）、长列表滚动流畅、包体积 ≤2MB（超出即分包）、图表页内存与反复进出无卡顿；
- **兼容**：刘海屏/安全区、深色模式、不同微信版本、字体放大；
- **网络异常**：断网/弱网/接口超时/空数据的兜底 UI 与重试；
- **合规走查**：每页口径标注与免责声明存在、无红线词、隐私弹窗可用。

### 2.3 内测与验收
体验版自用/小圈子内测 → 问题登记-修复-回归闭环；验收标准对齐 §6 M4（内测问题修复、对账达标）。

## 3. M5 提审材料清单（草稿）
1. 主体与资质：企业主体注册 + 微信认证 + 类目资质（M5 开工按后台现行要求核对）；暂不公开上架可仅体验版内测跳过；
2. 小程序 ICP 备案完成；
3. 类目选择与服务描述：强调"数据工具、估算值、不构成投资建议"，规避敏感词；
4. **免责声明（草案）**：本小程序展示的 ETF 资金流入估算数据基于公开信息推算，为估算值而非真实成交数据，可能存在误差、遗漏或延迟；所有内容仅供信息参考与研究学习，不构成任何投资建议、推荐或收益承诺。市场有风险，投资需谨慎。数据来源于公开渠道（交易所披露、天天基金、东方财富等），本产品不保证其准确性、完整性与及时性；
5. **数据说明文案（草案要点）**：公式 Flow(i,t)=Σ[Δ份额(e,t)×单位净值(e,t-1)×权重(e,i,t)]；权重优先 PCF 申赎清单、回退季报持仓（滞后 1–2 个月）；每日盘后 T+1 更新；界面数据统一标注"估算值"；
6. 隐私协议：后台《用户隐私保护指引》配置 + 页内协议（要点见 §1.5）；
7. 提审素材：各页面截图、页面路径、测试账号（如需登录）、版本描述；
8. 数据来源与更新时间标注走查。

## 4. 预留问题清单（M4 前需关闭）

2. 仅展示"估算资金流"是否仍触发沪深交易所行情许可要求？（咨询官方或试审反馈）
3. 免费数据源商用条款逐一确认（天天基金/东财/交易所披露/AKShare 聚合层）；
4. 订阅消息模板类目合规性与审核话术；
