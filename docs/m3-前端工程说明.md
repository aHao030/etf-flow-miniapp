## 3. 图表：echarts-for-weixin 接入说明

- `flow-chart` 组件已从原生 canvas 占位实现替换为 **ec-canvas（官方组件，ecomfe/echarts-for-weixin master）+ echarts**；对外 props 不变（series/seriesKey/chartType/unitText/unitDiv/footnote），**页面零改动**；
- echarts 构建：本环境无打包器（无法在线按需裁剪），采用官方 **echarts.simple.min.js 精简构建**（重命名为 ec-canvas/echarts.js，454KB，含 bar/line/grid/tooltip/legend/title，已校验字符串注册完整）；后续可替换为自定义裁剪构建（同名覆盖即可，预计可再减半）；
- 分包体积：echarts 454KB 位于 package-detail 分包（分包限 2MB），主包不含图表代码；
- 性能约定落实：图表数据仅经 `chart.setOption` 进 canvas、**不进 setData**；序列点 ≤60（契约上限），双序列冗余安全；`animation: false`；组件 detached 时 dispose；
- 深市积累期 ETF（如 159915）序列仅 1 点或全 null 时组件显示「暂无序列数据」空态。

## 5. 联调发现的问题（已汇总 Lead / backend-dev）

1. **weight_source 超出契约枚举**：契约 §2.4 枚举为 `index|quarterly|none`，后端实际返回 `index_csindex(000300)`、`report(2026Q2)`（stock.quality、top_etfs、etfs 清单三处）。前端已做前缀兼容映射（index*→指数权重、report*/quarterly*→季报持仓），**建议 backend-dev 归一化为契约枚举**（或升级契约枚举）；
2. **coverage 口径不一致**：契约约定 0–1，后端返回 0–100（如 99.57）。前端 `covPct()` 已双口径兼容（>1 视为百分比），建议 backend-dev 按契约返回 0–1 或明确升版；
3. **深市积累期 ETF 序列近乎空**：159915 等 share_series 仅 1 点、top_stocks 为空——符合预期（note 已提示），前端空态兜底正常；
4. **HTTP 404 语义**：错误码走 HTTP 状态 + 信封，wx.request success 回调可正常读到 envelope（前端已按此实现），无需变更。
